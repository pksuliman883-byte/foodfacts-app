# 🍽️ FoodFacts App

A React app that allows users to search for food items and view their nutritional information using the Open Food Facts API.

## 🚀 Features

- Search for any food
- View nutrition data (calories, protein, carbs, fat)
- Displays results as clean cards
- Handles loading and empty states

## 🛠️ Tech Stack

- React (Vite)
- JavaScript (ES6)
- Fetch API
- CSS

## ▶️ How to Run

```bash
npm install
npm run dev
